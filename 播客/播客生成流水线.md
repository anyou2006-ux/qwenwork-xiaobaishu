# 《千问办公小白书》播客生成流水线（v3 定调版）

第 01 集（第 01 章）已定调为 v3，以下参数和流程是其余 11 章（第 02–12 章）必须照抄的"调子"。

## 一、声音（男女声对调的秘诀）

ListenHub 播客模式：**第一个 speaker 当提问方，第二个 speaker 当讲解方**。

- **男声 = 小周（新手，提问/质疑）**，放第一个 `--speaker-id`：
  `doubao-official-zh_male_linjiananhai_uranus_bigtts`（邻家男孩 2.0）
- **女声 = 林姐（老手，讲解/总结）**，放第二个 `--speaker-id`：
  `doubao-official-zh_female_cancan_uranus_bigtts`（知性灿灿 2.0）

## 二、脚本模板（作为 source-text 传入，精简版即可）

ListenHub 会重新生成对话，不会逐字念脚本；所以脚本的作用是**引导核心观点 + 守住红线 + 约束结尾**，不用写完整逐字对话，写"单集卡 + 关键要点"即可（约 800–1200 字）。

模板结构（每章替换内容）：

```
【生成约束】这是《千问办公小白书》第 X 集的双人播客。男声是新手（提问、质疑、把听众的疑问说出来），女声是老手（讲解、举例、给结论）。结尾保持克制，不要升华、不要喊口号，不要用"终极/真相/使命/救赎"这类词，聊完就收。

【本章核心观点】（一句话，抓一个点）

【开场钩子】（一个真实办公痛点场景，第一人称）

【要点1】（核心观点 + 一个类比或例子）

【要点2·质疑位】（新手抛出的疑问：会不会取代我/这能信吗/有没有坑；老手收回来：落到人负责、判断、验收）

【一个动作】（听完就能做的一件小事，具体到"今晚就试"）

【收尾】（一句克制的总结，不升华）

【红线】
- 不把"AI 会不会思考"说死（说"我们不用急着下结论，重要的是谁判断、谁签字"）
- 责任落到有相应权限的人
- 不拉踩竞品（提同类只说"同类赛道"）
- 产品能力/入口写"截至 2026 年 9 月"
- 举例用真实可查的，或标"打个比方"
```

## 三、CLI 生成命令（每章）

```bash
listenhub podcast create \
  --query "<第X章标题>：<核心观点一句话>" \
  --source-text "<上面【生成约束】+【红线】段>" \
  --source-text "<脚本正文（单集卡+要点）>" \
  --lang zh \
  --mode deep \
  --speaker-id doubao-official-zh_male_linjiananhai_uranus_bigtts \
  --speaker-id doubao-official-zh_female_cancan_uranus_bigtts \
  -j
```

`-j` 返回 JSON，其中 `audio.data.audioUrl` 是音频地址，`scripts.data[]` 是逐句台词（含 `speakerInnerId`，可用于核对男女声是否对调）。

## 四、切尾段（ffmpeg）

ListenHub 总会在结尾自动加一段升华独白，必须切掉：

1. 下载音频后，用 `ffmpeg -i x.mp3 -af "silencedetect=noise=-32dB:d=0.4" -f null - 2>&1 | grep silence_start` 找静音段。
2. 定位**最后一段升华独白开始前**的换人停顿（通常是结尾附近一个 0.7s 以上的静音段，之后到音频末尾是连续的长独白）。
3. 用该停顿的时间点切：`ffmpeg -y -i x.mp3 -t <切点秒> -af "afade=t=out:st=<切点-1.6>:d=1.6" -c:a libmp3lame -b:a 128k x-v3.mp3`

判断依据：结尾升华段通常是一段 250 字左右、持续约 45–55 秒的连续独白；它前面的换人停顿比独白内部的换气停顿（0.4–0.6s）更长。

## 五、红线自查（每章脚本写完必过）

1. 不把"AI 会不会思考"说死
2. 数据/案例可查或标"打比方"
3. 价值判断标立场，不当事实
4. 产品细节标"截至 2026 年 9 月"
5. 不把交付写成甩锅（责任落到有权限的人）
6. 不拉踩竞品
7. 组织规则优先于个人判断
8. 术语一致

## 六、每章交付物

- 脚本文件：`播客/第XX集-XX章-<标题>-脚本-v1.md`
- 音频文件：`播客/第XX集-XX章-<标题>-v3.mp3`（切尾后）
- 报告：切点、时长、扣了多少 credits、红线是否守住、男女声是否对调
