# STORYBOARD — 把需求说清

## Video direction

- **palette:** 白底 + 深绿文字 `#155f33` / `#114a28`；亮绿 `#39d377` 只做块面、描边、圆点、图标，不做白底正文字色；警示语义用深琥珀 `#a0611a`，不作为正文小字色。
- **type:** LXGW WenKai（霞鹜文楷）；标题用 Bold，正文用 Regular。
- **rhythm / motion:** 单时间轴、seek-safe；每帧开场 0.4s 内完成主体入场；节拍器一致（0.6s 出、0.9s 定）。hook 快 → 命名停 → 对比展开 → 递进加重 → 卡片扫描 → 瓷片点射 → 金句放慢 → CTA 收。
- **topbar:** 全片统一「需求要先说清 · NN — 08」。
- **octopus:** 章鱼一律用 `assets/octopus.html` 的标准章鱼（细黑线轮廓 + 白眼球黑眼珠 + 短眉 + 微笑 + 4 条触手 + 头顶一枚实心 `#39d377` 圆点），禁止整只涂成实心绿。
- **Voice:** Kokoro `zf_xiaobei`，75 秒单口，speed 1.0 零提速。
