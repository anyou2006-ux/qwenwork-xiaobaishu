# 千问办公小白书

> 从“会不会用电脑”，到“会不会让 AI 干活”。

一本讲怎么把你自己，变成用得起、用得动、用得上办公智能体（千问办公 / QwenWork）的书。

## 这是什么

- 不是“千问办公操作手册”，也不是“功能说明书”。
- 是三个核心思维（**判断 → 流程 → 递归**）+ 一条分工线（**提需求、验收、担责任**）的通用办公 AI 使用方法论。
- 与腾讯 WorkBuddy、字节豆包、360 纳米等同属“办公智能体 / AI Agent”赛道，本书**不做横向对比**。
